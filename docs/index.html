03Why it works

Agents love shortcuts. Kiln closes them.

Left alone, agents skip specs, tests, and reviews, which are exactly what make software trustworthy. Four mechanisms keep the bar high.

01

Excuses are rebutted in advance

Every skill lists the excuses agents use to skip a step, each with its answer.

"I'll add tests later."Write them now, while the edge cases are fresh.
"This is too small to review."A small bug in production is still a bug.
02

Done means proven

Every skill ends with exit criteria: passing tests, a successful build, desktop and mobile screenshots, or Lighthouse numbers. No evidence, not done.

03

Four specialists check every release

/ship calls a code reviewer, an accessibility auditor, a speed auditor, and an SEO auditor at once, then merges their findings into one decision: ship or hold.

04

The skills are measured too

Each skill's structure is checked, its description is tested so it never collides with another skill, and its real output is compared against an agent without it.

04Ship panel

Ship past a panel, not a rubber stamp.

/ship runs a pre-launch checklist and sends your work to four specialists in parallel. Different perspectives, one verdict.
